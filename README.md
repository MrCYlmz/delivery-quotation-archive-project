# delivery-quotation-archive-project

> **Early-stage test. Not ready for use.**
>
> This repository is a demonstration only. It is an early test of
> [dew-agent-factory](https://github.com/MrCYlmz/dew-agent-factory) applied to one
> real project. Expect it to change, break or disappear without notice. Do not
> build on it.

## What this is

The team-lead workspace generated by dew-agent-factory for the delivery quotation
archive application. It holds no application code. It holds:

- `CLAUDE.md`: the team lead's instructions for running stories.
- `.claude/agents/` and `.claude/skills/`: the workers (developers, unit testers,
  reviewers) and their rule sets.
- `playbook.md`, `general-open-points.md`, `story-index.md`: decisions, open
  points and the log of closed stories.

The application the team built is published as a demonstration snapshot at
[dew-delivery-quotation-manager-demo](https://github.com/MrCYlmz/dew-delivery-quotation-manager-demo): no security checks, not for use.
